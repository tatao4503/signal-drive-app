## 이번 수정

- 작은 시계 보정이 누적돼도 원천 데이터 신선도·만료 시간이 늘어나지 않도록 경과시간 하한 적용. 시계 무효 상태는 명시적 새 세션 전까지 유지.
- 주행 카드의 현장 신호 우선 안내 유지. 낮은 가로 화면에서 출처·색·숫자·안내를 함께 표시하고, 주행 전환 후 맨 위로 이동.
- 비대화형 입력·서명 누락·빌드 실패를 성공으로 처리하지 않음. 키스토어의 실제 경로가 소스 밖인지 확인하고 기존 APK를 덮어쓰지 않음.
- 기기 선택·설정 복구·설치본 해시·소스 목록 해시를 기록. 증거 저장 실패보다 설정 복구를 먼저 수행.

## 한계

화면 신호는 합성 시연 데이터입니다. 서버와 APK의 승인 매핑은 0건이고 실제 API 수신·교차로 방향 매핑·현장 정확도는 검증하지 않았습니다. 3초 신선도 설정은 개발 설정입니다.

AAOS 시험은 기어 D·주차 브레이크 해제로 만든 공회전(idling)의 제한 상태입니다. 지속 moving·차량 서비스 재연결·Pleos SDK/에뮬레이터·실차는 미검증입니다. DO 선언과 이번 통과 수는 주행 사용 승인·안전성·사고 감소 효과를 증명하지 않습니다.

제공 DOCX를 바탕으로 만든 신청서 개정 복사본은 별도 폴더에 있으며 본인 확인·서명·날짜가 필요합니다. 공개 저장소 `tatao4503/signal-drive-app`의 존재·공개 상태는 확인했으나 이번 0.2.1의 업로드·메일 발송·공모전 접수는 수행하지 않았습니다.
